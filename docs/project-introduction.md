# AquaAgent 项目介绍

AquaAgent 发布既有 fool fish 水产观察平台的源码，围绕“观察—补充证据—人工核对—病例随访”组织工作。实际架构为 React 前端、Node.js 后端和本机 JSON 状态，不采用早期设计文档中的 Java / Spring / MySQL 架构。

主 Agent 在受限工具集合中决定是否检索资料；视觉与建议角色各自处理图像特征和综合提示。服务端验证权限、参数、调用预算与引用编号，人工决定任务是否采纳及病例是否结案。模型没有病例审批或删除权限，也没有通用文件读取和设备控制工具。

病例与真实任务独立管理，历史和附件保存在使用者本机。公开源码附带虚构流程演示和自制静态池塘示意；不附带真实病例、模型权重、训练数据或知识资料全文。摄像头任务需明确云端处理同意，自动分析默认关闭。

自动化测试验证软件规则，不能证明病害识别准确率、临床效用或论文创新贡献。发布版不宣称无人值守养殖、自动治疗或全天后台巡检。本轮不调用付费模型服务；真实连接由使用者配置后验证。
